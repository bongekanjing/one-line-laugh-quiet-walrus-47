## The line

> I have moved a box labelled 'cables, probably' through four apartments in six years without once opening it. It is not a box anymore, it is an heirloom.

## Why this one

The judge weighs three things: a real surprise at the end that still makes
sense, an everyday truth people recognise, and economy of words.

*An everyday truth.* Everyone who has moved house more than once owns a box
they have never unpacked and cannot throw away. The line names a specific,
absurd-but-exact object — "cables, probably" — and the hedge in that label is
the whole reason the box survives. You did not label it; you estimated it.

*A surprise that still makes sense.* The turn is the last word. "Heirloom"
promotes a box of mystery wire from rubbish to inheritance, and because the
sentence has just told you it has been carried through four homes by hand,
the elevation lands as obviously true instead of as a joke bolted on.

*Economy.* 152 characters, two short sentences, no adjective doing work the
noun could do. "Through four apartments in six years" carries the elapsed time
and the physical labour in one clause, so the punchline arrives with the
reader already believing the box has a history.

The first draft ended "it is not a box, it is a commitment". That is the same
idea reached too early — "commitment" is abstract, so the reader has to do the
promotion themselves. "Heirloom" does it for them and is funnier for being
concrete.

## Run it

```
node main.ts
```

The program writes the line to `/output/entry.txt` (override with `ENTRY_OUT`)
and refuses to write it unless it is 1–200 characters, not whitespace only, free
of doubled spaces, and closed with a full stop. Anything else exits non-zero.
